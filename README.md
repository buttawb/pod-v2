# Proof-of-Delivery v2 - Driver App

Android app (React Native / Expo) for couriers: work today's stop list, capture proof-of-delivery evidence offline, and reconcile it with the server when signal returns.

Backend, infrastructure, and the design write-up live in the companion repository: **[pod-v2-backend](https://github.com/buttawb/pod-v2-backend)** (see its `DECISIONS.md` for the data model, sync protocol, and migration plan).
